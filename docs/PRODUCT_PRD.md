# IELTS Quest

Version: 1.0.0

---

# Product Overview

IELTS Quest is a story-based IELTS vocabulary learning platform.

The learning flow is:

Study Story
→ Learn Vocabulary
→ Complete Quiz
→ Review Mistakes
→ Finish Mission

The purpose of the software is to help users remember IELTS vocabulary naturally through stories instead of memorizing isolated word lists.

---

# Target Users

- IELTS learners
- English beginners
- Users who dislike rote memorization
- Users learning 15–30 minutes per day

---

# Story Rules

Every story must:

- Be easy to understand.
- Follow a complete storyline.
- Introduce vocabulary naturally.
- Increase difficulty gradually.
- Include sentence-by-sentence translation after finishing.

---

# Quiz Rules

Each Mission contains:

- 6–10 vocabulary questions.
- Randomized order.
- Instant score.
- Correct answers.
- Retry support.

---

# Dictionary Rules

Each vocabulary item contains:

- Word
- IPA
- Part of Speech
- Chinese Meaning
- English Definition
- Example Sentence

Audio pronunciation will be added later.
